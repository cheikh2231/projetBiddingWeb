# 🔨 Plateforme d'Enchères en Ligne (PHP | JS)

Une application web interactive permettant aux utilisateurs de consulter des articles, de participer à des enchères en direct et de suivre l'évolution des offres. Ce projet met en avant des interactions dynamiques côté client (JavaScript) et une logique métier sécurisée côté serveur (PHP).

## 🚀 Fonctionnalités principales

**👤 Espace Utilisateur (Enchérisseur) :**
- Exploration du catalogue d'articles.
- Système d'enchères avec validation de l'offre (vérification que la nouvelle offre est supérieure à l'actuelle).
- Compte à rebours dynamique (JavaScript) indiquant le temps restant pour chaque enchère.

**👨‍💼 Espace Administrateur / Vendeur :**
- Ajout, modification et suppression d'articles mis aux enchères (CRUD).
- Définition du prix de départ, de la description et de la durée de l'enchère.
- Suivi des enchères remportées.

## 🛠️ Stack Technique
- **Front-end :** HTML5, CSS3, JavaScript (Vanilla)
- **Back-end :** PHP
- **Base de données :** MySQL
